# Web 验收案例（用户执行）

遵循根目录 [CLAUDE.md](../CLAUDE.md)：AI 仅执行核心功能单元测试。以下 Web、客户端、前端、构建、浏览器及真实模型验收由用户执行；AI 不代为执行。

## 测试命令

在 `web/` 下执行：

```sh
npm ci
npm test                  # 核心单测，AI 可执行
npm run test:web          # 用户执行：HTTP/API、会话与双协议端到端
npm run test:client       # 用户执行：Markdown 安全与 React 交互
npm run build            # 用户执行：前后端类型检查及生产构建
```

`test:web` 使用本机模型替身，真实调用 Pi SDK，不需要外部凭证。它验证两种协议的地址、认证头、模型和工具白名单、工具循环、上下文、来源及只读文件摘要。替身预设的回答用于验证执行链路，不代表真实模型的答案质量通过。

`test:client` 使用 JSDOM，验证流式显示、停止、重试、引用打开、Raw 跳转、返回和新建对话；不替代真实浏览器的布局与响应式验收。

## 真实模型与 demo-wiki 验收

```sh

# 在 .env 中填写 LLM_BASE_URL、LLM_MODEL、LLM_API_KEY。
# Anthropic 的 LLM_BASE_URL 不带 /v1；OpenAI 兼容接口通常带 /v1。
```

打开 `http://127.0.0.1:5174`，依次提问；同时观察页面进度和后端日志中的工具名称。答案必须核对引用正文，不能只看模型是否给出了回答。

| 编号 | 问题 / 操作 | 必须核对的答案与轨迹 |
| --- | --- | --- |
| DEMO-01 | 用户参与抽奖需要满足什么条件？ | 每轮读取 schema、index 并搜索；阅读活动准入、频率风控、尝试计数与流程正文中相关条款；保留次数、时间等条件；引用可打开；不编造固定阈值 |
| DEMO-02 | 这些规则约束哪些流程？ | 真实调用 `wiki_relations`，使用已存储的出边/入边作答；不能只做关键词搜索；逆关系来自 schema |
| DEMO-03 | 抽奖活动有哪些状态？ | 读取 StateMachine 正文，说明生命周期来自教学补充来源，不能说成原技术文章中的事实 |
| DEMO-04 | 连续追问：这个结论的原始依据是什么？ | 保留上轮上下文；调用 `read_document` 阅读 `raw/demo-spec/2026-10-15-lottery-lifecycle.md`；Raw 引用可打开 |
| DEMO-05 | 活动预算是多少？ | 明确知识库没有预算依据，不编造金额；说明未知项 |

| DEMO-07 | 同样的问题分别用两种协议提问 | 各自配置正确、可流式回答；没有凭证的协议记为“未做真实连接验证” |

可选脚本（会把示例问题和知识内容发送给配置的模型，仅由用户执行）：

```sh
npm run smoke:live
```

它连续执行五个 demo 问题，输出答案与工具名称，并检查关系查询、Raw 读取及查询前后 `wiki/`、`raw/` 文件摘要不变。仍需人工核对答案、来源、条件和教学来源说明。

## 错误与安全案例

仅在副本 Wiki 或临时文件中制造异常，完成后恢复配置。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| ERR-01 | 留空 `LLM_API_KEY` / 配错协议 / WIKI_ROOT 不存在后启动 | 明确指出配置项，不显示密钥；没有模型请求 |
| ERR-02 | 将副本来源改为不存在的链接，点击它 | 显示来源读取错误，不伪装成已验证文档 |
| ERR-03 | 提交越界、符号链接越界、非文档路径；从外站 Origin 或伪造 Host 请求 API | 400/403 拒绝；不泄露本机绝对路径和内容；自动用例见 `test:web` |
| ERR-04 | 临时将 `QUERY_MAX_TOOL_CALLS=1`，重启后提问 | 页面提示“这次需要查阅的资料较多，请缩小问题范围后再试”，不显示工具上限等术语；本轮不进入后续上下文；不自动重复请求模型 |
| ERR-05 | 配置很小的超时时间，或生成中断开连接 | 取消当前任务、保留已有显示、可重试；未完成工具调用不进入新轮次 |
| ERR-06 | 同会话并发提交两次 / 使用过期或未知会话 | 返回 409 / 404，并给出可理解的错误 |
| ERR-07 | 长对话超过模型容量 | 提示新建对话；不静默压缩或丢弃历史 |
| ERR-08 | 来源加入 HTML、脚本、远程图片和危险协议链接 | 不执行 HTML/脚本、不自动加载远程图片、不跳转危险协议；自动用例见 `test:client` |
| ERR-09 | 生成后改动副本 Wiki 内容，再在同会话提问 | 重新读取当前文件，不能沿用旧缓存作为新证据 |

## 固定端口验收（用户执行）

- `web/.env` 设置 `PORT=3002`、`WEB_PORT=5174`，运行 `npm run dev`：前端固定使用 5174，后端固定使用 3002；重复启动应报端口占用，不应变为其他端口。
- 停止开发服务后，运行 `npm run build` 和 `npm start`：生产页面固定使用 `PORT`（默认 3002）。
- 修改为另一组不同端口并重启：页面地址、API 代理和开发访问校验均使用新配置，不应仍指向 5174 或 3002。
- 两个端口设为相同值或无效值：启动明确报错，不自动挑选端口。
- 本次 AI 只运行端口解析等核心单测；以上启动和 Web 验收由用户执行。
